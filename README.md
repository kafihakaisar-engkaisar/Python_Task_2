# Expense Tracker (Python Task 2)

A simple and interactive Command Line Interface (CLI) based Expense Tracker built with Python. It allows users to log expenses, view recorded items, and calculate total spending, storing all data in a local CSV file.

## Features

- **Add Expense**: Log an expense description along with its amount.
- **View All Expenses**: Display all recorded expenses formatted with item description and cost in ₹.
- **View Total Spent**: Calculate and view the total expenditure.
- **CSV Data Persistence**: Stores all entries in [`expenses.csv`](expenses.csv).

## Project Structure

- [`expense_tracker.py`](expense_tracker.py): Main script containing the CLI menu and logic.
- [`expenses.csv`](expenses.csv): CSV file storing transaction records.

## How to Run

### Prerequisites
- Python 3.x installed.

### Execution
Run the script in PowerShell or terminal:

```bash
python expense_tracker.py
```
